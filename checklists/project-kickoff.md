# Checklist de kickoff

- [ ] Objetivo del proyecto definido
- [ ] Alcance aclarado
- [ ] Stakeholders identificados
- [ ] Requisitos funcionales documentados
- [ ] Reglas de negocio entendidas
- [ ] Entregables definidos
- [ ] Riesgos analizados
- [ ] Cronograma aprobado
- [ ] Estructura del repositorio creada
- [ ] README inicial redactado
- [ ] Dependencias y herramientas revisadas
- [ ] Seguimiento y comunicación definidos
